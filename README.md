# Bitten

Bitten is a C2C marketplace for used Apple devices,
focused on technical verification and listing quality.

## Technology Stack

- Python 3.13
- FastAPI
- PostgreSQL
- Podman
- Google Cloud Platform
- Terraform
- GitHub Actions

## Project Status

Module 0: Developer environment setup.
